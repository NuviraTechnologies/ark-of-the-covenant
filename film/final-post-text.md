AI agents are getting wallets everywhere — and one poisoned instruction, hidden in anything the agent reads, can empty the wallet in a single call. Nothing between the agent and the chain can say no. So I built the thing that says no.

The Ark of the Covenant is a vault on @NEARProtocol. The agent holds only a scoped function-call key — it can ask, it can never just take. Every release is bound to a recipient, an amount, and a purpose, signed by a gate, and verified by the contract itself before funds move.

Watch the demo: a live drain attempt on testnet hits the blocklist and the contract refuses it. Attacker's balance: zero. Code: https://github.com/NuviraTechnologies/ark-of-the-covenant Vault: https://testnet.nearblocks.io/address/ark3vault2120.testnet What should an agent vault refuse that this one doesn't yet? #NEARHackathon @NearLegion
